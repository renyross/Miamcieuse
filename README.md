# 🥜 MIAM'CIEUSE — Le goût de la pure satisfaction

Site web e-commerce officiel de **Miam'cieuse**, marque artisanale haïtienne spécialisée dans le véritable Mamba (beurre de cacahuètes torréfié à cœur), la cassave traditionnelle pur manioc, le chocolat pays grand cru et les saveurs authentiques d'Haïti.

---

## 🌟 Fonctionnalités Principales

- **Application E-commerce Moderne** : Présentation des produits avec galerie, sélecteur de formats (16 oz, 32 oz), packs gourmands et calcul des prix.
- **Panier Interactif & Dynamique** : Gestion des quantités, jauge dynamique de livraison offerte dès 45 €, code promo et commande directe sur WhatsApp.
- **Recherche & Filtres Avancés** : Recherche instantanée avec autocomplétion, filtres par catégorie, curseur de budget et tris intelligents.
- **Avis Clients Authentiques** : Section témoignages épurée avec accès direct au profil et Reels Instagram de la marque.
- **Pages Dédiées & Navigation SPA** :
  - **Foire Aux Questions (FAQ)** avec recherche par mot-clé et accordéons thématiques.
  - **Modalités de Livraison** détaillant les expéditions à Pétion-Ville (24h), en provinces (48-72h) et pour la diaspora (USA, Canada, France).
  - **Nous Contacter** avec formulaire interactif et coordonnées directes WhatsApp/téléphone.
  - **Notre Histoire & Racines** valorisant l'héritage Taïno et l'artisanat haïtien.
  - **Blog & Recettes** avec articles de fond et recettes traditionnelles.
- **Support Bilingue** : Interface prête en Français 🇫🇷 et Kreyòl Ayisyen 🇭🇹.

## 🚀 Démarrage Rapide

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
- npm ou yarn

### Installation
```bash
# 1. Cloner le dépôt
git clone https://github.com/VOTRE_NOM/miamcieuse.git

# 2. Entrer dans le dossier
cd miamcieuse

# 3. Installer les dépendances
npm install
```

### Lancer le serveur de développement
```bash
npm run dev
```
Le site sera accessible localement sur `http://localhost:3000`.

### Compiler pour la production
```bash
npm run build
```
Les fichiers prêts pour le déploiement seront générés dans le dossier `dist/`.
